# Rosetta AI - Frontend Web Interface 🖥️

## Purpose
The frontend provides an intuitive user interface for developers:
- Split-pane code editor (Source Code ➡️ Translated Code).
- Real-time language selector and translation trigger.
- Visual inspection of AST structure, translation metrics, and syntax error alerts.
